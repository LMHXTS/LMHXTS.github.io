    电动力学第一章：电磁现象的普遍规律 复习笔记

    一、核心物理概念

    1. 近距作用观点（场的观点）

    电荷与电流在周围空间激发电磁场，并通过场来传递相互作用。相比于认为作用力无需媒介瞬时传递的"超距作用"，实践证明近距作用观点是正确的。

    2. 涡旋电场

    由变化的磁场在空间中激发的非静电性质电场。其电力线具有涡旋状结构，无发源点与终止点，沿闭合回路的环量一般不为零。

    3. 位移电流

    物理实质是电场的变化率，数学表示为：

    \[\vec{J}_{D} = \epsilon_{0} \frac{\partial\vec{E}}{\partial t}\]

    它是麦克斯韦为了解决变化电磁场下安培环路定律与电荷守恒定律的严重矛盾而提出的假设，证明了变化的电场能够激发磁场。

    4. 束缚电荷与诱导电流

    电介质极化：在外电场作用下，电介质分子正负电荷中心发生相对位移或有规则取向，从而在宏观上产生束缚电荷。其体密度为 \(\rho_{P} = -\nabla\cdot\vec{P}\)；分界面上的面密度为 \(\sigma_{P} = -\vec{n}_{12}\cdot(\vec{P}_{2}-\vec{P}_{1})\)。

    介质磁化：在外磁场作用下，分子电流呈现有规则取向，从而形成宏观磁化电流，其体密度为 \(\vec{J}_{M} = \nabla\times\vec{M}\)。

    极化电流：当电场随时间变化时，介质极化强度发生变化所引起的电流，其密度为 \(\vec{J}_{P} = \frac{\partial\vec{P}}{\partial t}\)。

    二、核心公式：麦克斯韦方程组

    1. 真空中的麦克斯韦方程组

    由基本场量电场强度 \(\vec{E}\) 和磁感应强度 \(\vec{B}\) 描写：

    \[ \begin{aligned} \nabla\times\vec{E} &= -\frac{\partial\vec{B}}{\partial t} &&\text{（法拉第电磁感应定律：变化磁场激发电场）} \\[6pt] \nabla\times\vec{B} &= \mu_{0}\vec{J} + \mu_{0}\epsilon_{0}\frac{\partial\vec{E}}{\partial t} &&\text{（麦克斯韦位移电流假设：电流和变化电场激发磁场）} \\[6pt] \nabla\cdot\vec{E} &= \frac{\rho}{\epsilon_{0}} &&\text{（高斯定理：电荷是电场的源）} \\[6pt] \nabla\cdot\vec{B} &= 0 &&\text{（磁场无源性：没有磁单极子，磁力线闭合）} \end{aligned} \]

    2. 介质中的麦克斯韦方程组

    引入了辅助物理量电位移矢量 \(\vec{D}\) 和磁场强度 \(\vec{H}\)：

    \[ \begin{aligned} \nabla\times\vec{E} &= -\frac{\partial\vec{B}}{\partial t} \\[6pt] \nabla\times\vec{H} &= \vec{J}_{f} + \frac{\partial\vec{D}}{\partial t} \\[6pt] \nabla\cdot\vec{D} &= \rho_{f} \\[6pt] \nabla\cdot\vec{B} &= 0 \end{aligned} \]

    概念辨析：\(\vec{D}\) 的散度仅由自由电荷密度决定；而 \(\vec{E}\) 的散度由自由电荷与束缚电荷共同决定。

    3. 介质的电磁性质方程（本构关系）

    对于各向同性线性介质，满足以下线性实验规律：

    • \(\vec{D} = \epsilon\vec{E}\)（其中 \(\epsilon = \epsilon_{r}\epsilon_{0}\)，\(\epsilon\) 为介质介电常数）
    • \(\vec{B} = \mu\vec{H}\)（其中 \(\mu = \mu_{0}\mu_{r}\)，\(\mu\) 为介质磁导率）
    • \(\vec{J} = \sigma\vec{E}\)（常规导电物质中的欧姆定律）

    三、电磁场边值关系

    在两介质分界面上，物理量发生跃变，微分形式方程组不再适用，需使用边值关系来约束界面两侧的场强。

    场量分量 边值关系公式 物理意义描述
    \(\vec{D}\) 的法向分量 \(D_{2n} - D_{1n} = \sigma_{f}\) \(\vec{D}\) 的法向跃变取决于分界面上的自由电荷面密度
    \(\vec{B}\) 的法向分量 \(B_{2n} = B_{1n}\) \(\vec{B}\) 的法向分量跨越界面时保持连续
    \(\vec{E}\) 的切向分量 \(\vec{n} \times (\vec{E}_{2} - \vec{E}_{1}) = 0\) \(\vec{E}\) 的切向分量跨越界面时保持连续
    \(\vec{H}\) 的切向分量 \(\vec{n} \times (\vec{H}_{2} - \vec{H}_{1}) = \vec{\alpha}_{f}\) \(\vec{H}\) 的切向跃变取决于分界面上的传导电流线密度

    注：\(\vec{n}\) 为由介质 1 指向介质 2 的法线单位矢量。

    四、电磁场的能量与能流

    能流密度矢量（坡印亭矢量，Poynting Vector）

    \[\vec{S} = \vec{E} \times \vec{H}\]

    描述单位时间内垂直通过单位面积的电磁能量。

    电磁场能量密度 \(\omega\)

    • 真空情况：\(\displaystyle \omega = \frac{1}{2}\left(\epsilon_{0}E^{2} + \frac{1}{\mu_{0}}B^{2}\right)\)
    • 线性介质情形：\(\displaystyle \omega = \frac{1}{2}\left(\vec{E}\cdot\vec{D} + \vec{H}\cdot\vec{B}\right)\)

    场和电荷系统的能量守恒定律（微分形式）

    \[\nabla\cdot\vec{S} + \frac{\partial\omega}{\partial t} = -\vec{f}\cdot\vec{v}\]

    其中 \(-\vec{f}\cdot\vec{v}\) 为场对电荷系统做功功率密度的负值。该方程表明，能流密度的散度与能量密度随时间的变化率之和，等于电场对电荷做功功率密度的负值。

    经典例题物理结论（圆柱形导体能量流动）

    计算表明，导体内部由焦耳热引起的损耗功率（\(I^{2}R\)）等于外部空间中坡印亭矢量由导体表面垂直流入其内部的功率。这证明了导体的热功率是由外部电磁场能量流入导体内部而得到的。
